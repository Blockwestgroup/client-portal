Set up a client's documents

  1. In Google Drive, make a folder named after the client (one per client).
  2. Right-click it → Share → add the client's email as Viewer. Keep "General access" set to Restricted.
  3. Copy the folder link and paste it above.

Set up a deal calendar (optional)

  1. In Google Calendar, click + next to "Other calendars" → Create new calendar → name it, for example "Sam & Jordan – 123 Main".
  2. Add the contract deadlines to that calendar.
  3. Open its Settings → "Integrate calendar" → copy Secret address in iCal format and paste it above.

The link holds only what's on this page, never addresses or documents. Anyone with the link sees the client's first name and stage, and the documents still need their Google login.
